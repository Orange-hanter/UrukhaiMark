# Проверка архитектурной стратегии

> Статус: Living. Дата базовой оценки: 2026-09-01.  
> Назначение: отделить подтверждённые контракты от гипотез до начала разработки.

## 1. Правило принятия решений

Архитектура опирается только на первичную спецификацию, воспроизводимый sandbox-тест
или письменный ответ оператора. Исследования и материалы интеграторов формируют
гипотезу, но не регуляторный контракт.

Уровни доверия:

- **Confirmed** — первичная спецификация или воспроизводимый тест;
- **Probable** — согласованные вторичные источники, требуется подтверждение;
- **Unknown** — данных недостаточно; capability остаётся `future`.

## 4. Сквозные и отказные сценарии

| Сценарий | Ожидаемое поведение |
|----------|---------------------|
| Happy path cosmetics → РФ | Строгий pipeline, каждый переход и внешний ID в аудите |
| datamark недоступен | Локальные задания сохраняются; внешние операции retry с backoff |
| Print ACK, камера no-read | Экземпляр `needs_review`; линия не объявляет КМ verified |
| Камера вернула другой КМ | Оба экземпляра блокируются для ручной сверки |
| Повторная печать | Только явная команда с причиной и новым `print_attempt` |
| Потеря center↔edge | Агент расходует только арендованный диапазон; события остаются в outbox |
| Частичный короб | Упаковка остаётся `open`, состав версионируется |
| Перепаковка | Явные disaggregation/aggregation events, без переписывания истории |
| Ошибочная отгрузка | Локально не откатывается без подтверждённого внешнего документа |
| Восстановление БД/edge | Replay идемпотентен; сверка allocation и event offsets обязательна |

## 5. Quality gates

### Gate MVP

- подтверждённые GTIN, ТН ВЭД/ОКПД2 и `agent` контрагента;
- sandbox credentials и тестовые КМ с реальными `0x1D`;
- приняты ADR о topology и хранении КМ;
- согласована FSM и параметры `addMark`;
- определены интерфейсы принтера/сканера;
- sandbox E2E acceptance criteria утверждены.

### Gate промышленной линии

- измерена реальная скорость и расстояние print→verify;
- согласованы ACK/no-read/reject сигналы оборудования;
- утверждены правила reprint, waste и ручной проверки;
- пройдены тесты на 50/75/100% скорости;
- определены stop conditions для серии NOK.

### Gate edge

- есть бизнес-требование offline/multi-line;
- allocation lease, inbox/outbox и дедупликация протестированы;
- определены обновление, rollback, health и удалённая диагностика агента;
- offline-окно не нарушает срок регуляторной отчётности.
