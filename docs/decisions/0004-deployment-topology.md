# ADR-0004: Центральный модульный монолит с edge-ready контрактом

## Status

Accepted

## Date

2026-09-01

## Context

MVP обслуживает одну print station и не имеет подтверждённого требования непрерывной
работы при отказе центра. Полноценный edge с локальным КМ-буфером вводит распределённые
транзакции, дедупликацию, обновление агентов и дополнительную поверхность риска.
При этом будущие многолинейные предприятия могут потребовать изоляцию линий.

## Decision

Разворачивать Application API, Worker и PostgreSQL как self-hosted модульный монолит.
Взаимодействие с оборудованием идёт через `LineGateway` port внутри центрального
контура. Выделять тот же контракт в отдельный Edge Agent только после прохождения
multi-line/offline gate.

Edge использует ограниченные code allocation leases, durable outbox, at-least-once
events и идемпотентный inbox центра. Центр остаётся system of record.

## Consequences

MVP проще разрабатывать и эксплуатировать. Доменное ядро не зависит от vendor driver.
Будущее выделение edge не требует переписывать use cases, но потребует отдельной
системы доставки, identity, обновлений, reconciliation и локального шифрования.
